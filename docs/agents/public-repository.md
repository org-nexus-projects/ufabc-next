# Public repository

UFABC Next is open source. Treat repository files, commits, pull requests, issues, comments, CI logs, and release artifacts as public.

## Prepare public content

Keep conversations, private documents, local files, credentials, personal data, and internal context local by default.

Publish only the minimum information needed to implement, explain, or reproduce the work. Summarize requirements rather than quoting private conversations.

Sanitize examples, logs, stack traces, screenshots, and command output before they cross the public boundary.

## Public GitHub writes

Before creating or commenting on an issue, pull request, or other public GitHub surface:

1. Remove secrets, tokens, cookies, private URLs, environment values, student data, personal identifiers, local paths, and unrelated internal context.
2. Review the final sanitized content with the user.
3. Publish only after the user explicitly approves that final content.

If the public status of information is unclear, keep it local and ask.
