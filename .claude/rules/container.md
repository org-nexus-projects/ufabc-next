# Web app (Vue 3)

- Follow the layering in `apps/container/ARCHITECTURE.md`: pages compose components, components do not call
  HTTP directly, data flows through `@next/services` and TanStack Query (`useQuery`/`useMutation`).
- Query keys are arrays that start with the resource name and include every variable the request uses.
  Invalidate the matching keys after a mutation.
- Server state lives in Vue Query, not Pinia. Pinia is for client state (auth, UI preferences).
- Use `<script setup lang="ts">` and Vuetify components; keep styling consistent with neighbouring components.
- Text shown to users is Portuguese.
- `auto-imports.d.ts` and `components.d.ts` are generated by Vite plugins; never edit them.
- `apps/container/.env*` files are committed and public (`VITE_*`). Never put a secret there.
- New components and pages get a colocated `*.test.ts` using `render` from `@/test-utils` and MSW handlers for HTTP.
