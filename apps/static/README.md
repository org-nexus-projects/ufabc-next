# Static public site

`apps/static` é uma aplicação ativa com algumas paginas estáticas do UFABC Next.

## Scope

- `index.html` é a página principal.
- `privacidade.html` e `termos-de-uso.html` são páginas públicas de políticas.
- `assets/` contém os recursos servidos por essas páginas.

Não há pacote ou processo de build próprio neste diretório. Mantenha links, caminhos de assets e conteúdo público consistentes entre as páginas.

Antes de editar conteúdo destinado ao público, siga [as regras de publicação](../../docs/agents/public-repository.md).
